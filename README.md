# Стоматологія «Смайл Дент» (Полтава) — React 19 SPA

Сучасний інтерактивний веб-додаток стоматологічної клініки «Смайл Дент» у м. Полтава (вул. Григорія Левченка, 2).

## 🚀 Технологічний стек
- **React 19** + **TypeScript**
- **Vite 8** (швидка HMR-збірка та оптимізація бандлу)
- **Tailwind CSS v4** (`@tailwindcss/vite`, CSS-дизайн-система Medical Care)
- **React Bits**:
  - `SpotlightCard` — картка з інтерактивним радіальним відстеженням курсору миші
- **Magic UI**:
  - `ShimmerButton` — кнопка із динамічним світловим променем
  - `Marquee` — нескінченна стрічка соціального доказу (відгуки пацієнтів)
- **Strict Anti-Stretch Slider**:
  - Передбачає суворе маскування шарів через CSS `clip-path: inset(...)` та `object-fit: cover` без деформації пропорцій зображень
- **Lead Triad Integration**:
  - Повнофункціональне модальне вікно запису з маскою українських номерів `+380 (XX) XXX-XX-XX`, швидким переходом до Telegram та дзвінка
